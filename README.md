# Galaxy Conquest

This game was realised for the transeverse project for the second semester at EFREI.


## Exigences

This project was given to us to apply our skills and knowledge learnt in previous modules (notably **SP107I - General Physics** and __TI101 - Programming in Python__)

## Game conception

We wanted to make a strategy game in realtime, to follow the requirement of having trajectory in our game, we decided to implement gravitationnal forces that would be applied to the spaceship

## Realization
The game was made using the pygame module, and assets like planets and ressources were AI generated.

## Execution
To run the game, run main.py
### Keys
*Spacebar* - When on a planet, launch the spaceship, while in the air, activate the thrusters
*R* - Activate the RCS (Reaction Control System) to stop midair.
*Right click* - Point your ship towards your cursor
*E* - Open inventory
*S* - Send probes to find path to planets
*C* - Clear probe trajectories
*M* - Toggle Map view
